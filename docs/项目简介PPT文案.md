## 第 2 页：项目背景与意义
### 页面标题
从"数据富矿"到"数据资产"的最后一段路
### 正文内容
- 流程工业每天产生海量温度、压力、流量、产量与质量数据，数据价值密度高但利用率低
- 和利时深耕工业自动化与智能制造，数据链路完整，价值释放的瓶颈落在"分析"环节
- 三道门槛：分析门槛高（需会编程与算法）、分析周期长（小时级至天级）、安全顾虑重（不可控脚本）
- 项目意义：以自然语言为入口，把大模型变成"受控的工业分析引擎"
### 排版建议
- 左侧用"数据产生 → 数据采集 → 数据分析 → 决策优化"四步流程条，右侧列三道门槛图标
- 底部一句话总结，字号加大并使用强调色

## 第 3 页：需求痛点分析
### 页面标题
现场真正需要的，不是"更多数据"，而是"更快结论"
### 正文内容
- 工艺人员视角：会看工艺曲线，但不写 Python，分析需求依赖数据团队排期

- 需求归纳：零门槛输入、标准化算法、受控执行、产品化输出——四项缺一不可

## 第 4 页：系统总体架构
### 页面标题
五层架构，一条闭环
### 正文内容
- 交互层（Streamlit）：数据管理、自然语言分析、算法工具箱、系统状态
- 智能体层：意图解析 → 代码生成（含自修复）→ 执行编排 → 报告生成
- 安全执行层：子进程隔离、AST 白名单校验、目录限制、超时控制、环境脱敏
- 算法能力层：基础统计、相关性、时序时滞、异常检测、机器学习
- 数据与配置层：业务数据、环境配置、输出产物（图表 / 报告 / 模型 / 历史记录）
### 排版建议
- 竖向堆叠五个色块表示分层，层间用箭头表示依赖方向
- 右侧用环形箭头突出"提问 → 执行 → 报告"闭环，形成视觉焦点

## 第 5 页：核心功能展示
### 页面标题
七大功能覆盖工业数据分析全场景
### 正文内容
- 数据文件管理：CSV 上传、查看、删除，自动识别字段与数据类型
- 基础统计分析：均值、标准差、最值、中位数等描述性指标计算
- 高级数据分析：相关性分析、时序时滞分析、3σ 异常检测
- 机器学习建模：线性回归、决策树、随机森林的训练、评估、保存与推理
- 自然语言交互与代码安全执行：提问即出代码，代码受控运行
- 自动报告生成：图文并茂的结构化报告，支持 Markdown 与 HTML 导出

## 第 6 页：核心算法与技术亮点
### 页面标题
算法不炫技，只解决工业真问题
### 正文内容
- 描述性统计：偏度峰度刻画波动特征，变异系数实现跨量纲稳定性比较
- Pearson 相关性：自动挖掘强相关特征对，支撑变量解耦与特征筛选
- 时序互相关时滞分析：量化"先动后动"关系，滞后步数自动换算工艺时间，直接给出调节提前量
- 3σ 异常检测：同时输出 MAD 稳健阈值对照，规避重尾分布误报
- 随机森林回归：多指标评估 + 交叉验证 + 特征重要性，兼顾精度与机理解释
### 排版建议
- 五行横向条带，左侧方法名、中间一句话原理、右侧工业含义
- 时滞分析条带使用强调色，作为最具工业特色的能力突出展示

## 第 7 页：安全机制设计
### 页面标题
让大模型生成的代码"跑得动，也管得住"
### 正文内容
- 进程级隔离：独立子进程 + 独立空工作目录，以隔离模式执行，绝不使用 exec
- AST 白名单校验：仅放行数据分析类库，拦截系统级模块、危险函数与魔术属性
- 目录权限限制：绝对路径限定在数据与输出目录内，封锁文件枚举与删除操作
- 执行超时控制：超时即终止整个进程树，标准输出按上限截断
- 环境变量脱敏：密钥不进子进程，用户目录与临时目录重定向至运行目录
- 风险声明：子进程非强隔离边界，生产环境建议叠加容器与低权限账户
### 排版建议
- 五道防线做成"盾牌"纵向排列或环形防御图，每项一行要点
- 底部用浅色提示条给出残余风险与生产加固建议，体现严谨态度

## 第 8 页：运行效果演示

三个真实场景，一条闭环跑通

- 成果统计：七大功能全部完成，全量自动化测试 119 项全部通过
