# 项目概要介绍

> 命题方：和利时企业命题 ｜ 项目名称：工业数据分析 Agent 系统 ｜ 文档类型：项目概要介绍

## 一、项目背景与意义

流程工业（化工、石化、电力、冶金等）是国民经济的支柱产业，其生产过程中每时每刻都在产生海量运行数据：温度、压力、流量、液位、组分、产量与质量指标等。这些数据蕴含设备健康状态、工艺参数关联关系与质量波动规律，是智能制造的"富矿"。

和利时作为国内领先的工业自动化与智能制造解决方案提供商，长期服务于流程工业的集散控制系统（DCS）、可编程控制器（PLC）与智能工厂建设，积累了从现场仪表、控制系统到生产管理层的完整数据链路。然而在工程实践中，工业数据的价值释放仍面临三道门槛：

- **分析门槛高**：描述统计、相关性分析、时滞分析、异常检测与建模通常要求工程师掌握 Python、统计学与机器学习知识，现场工艺人员难以独立完成；
- **分析周期长**：一次完整的探索性分析往往需要数小时至数天，难以支撑生产过程中的快速决策；
- **安全顾虑重**：大模型自动生成并执行代码存在误操作与安全风险，工业现场对"不可控脚本"天然排斥。

本项目即面向上述痛点，基于大语言模型构建**自然语言驱动的工业数据分析 Agent 系统**。用户只需用中文描述分析需求（例如"分析蒸汽流量与出口温度之间的时滞"），系统即可自动完成意图解析、Python 分析代码生成、沙箱安全执行与图文报告输出，实现 **"用户提问 → 智能执行 → 自动报告"** 的完整闭环。这一模式不仅显著降低工业数据分析的使用门槛，也为大模型技术在工业现场的安全落地提供了可复用的工程范式，契合智能制造数字化转型的技术方向与和利时"数据驱动、智能决策"的业务定位。

## 二、项目核心目标

1. **自然语言驱动的零门槛分析**：将工艺人员的中文提问直接转化为可执行的数据分析流程；
2. **算法能力标准化**：沉淀覆盖统计、相关性、时滞、异常、建模的工业分析算法库，保证结果可复现、口径统一；
3. **代码生成与安全执行统一**：让大模型生成的代码"可用且可控"，通过沙箱机制将风险收敛在受控边界内；
4. **分析结果产品化**：自动输出包含文字结论、关键指标与统计图表的图文报告，支持归档与分享；
5. **离线可用与工程健壮**：在无外网、无 API 密钥的环境下仍可完整运行，具备工业级稳定性。

## 三、七大核心功能概述

| 序号 | 功能模块 | 功能说明 |
| --- | --- | --- |
| 1 | 数据文件管理 | 支持本地 CSV 的上传、查看与删除；自动识别字段名称、数据类型（数值/时间/分类/布尔）与缺失情况，形成数据画像 |
| 2 | 基础统计分析 | 对指定列计算均值、标准差、最大值、最小值、中位数、四分位数、偏度、峰度、变异系数等描述性指标，并绘制分布图 |
| 3 | 高级数据分析 | 相关性分析（Pearson/Spearman/Kendall 与强相关特征对挖掘）；时序时滞分析（互相关曲线与最优滞后步数）；基于 3σ 原则的异常检测（含 MAD 稳健阈值对照） |
| 4 | 机器学习建模 | 支持线性回归、决策树回归、随机森林回归三类模型的训练、评估、保存与推理，输出 MSE、RMSE、MAE、R² 与交叉验证结果及特征重要性 |
| 5 | 自然语言交互 | 解析用户中文提问，自动识别分析意图（八大意图类别），支持示例问题一键填充与多轮连续分析 |
| 6 | 代码生成与安全执行 | 由大模型按严格约束生成 Python 分析代码，经静态安全校验后在隔离子进程中执行，捕获执行结果、异常信息与生成的图表 |
| 7 | 自动报告生成 | 将执行结果的事实数据反馈给大模型，自动生成含结论、指标表、图表与建议的结构化报告，输出 Markdown 与自包含 HTML 两种格式 |

## 四、总体技术架构简述

系统采用五层架构，自下而上依次为：

- **数据与配置层**：`data/` 存放业务数据，`config/.env` 统一管理 API 密钥与运行参数，`output/` 归档图表、报告、模型与执行痕迹；
- **算法能力层（analytics）**：基础统计、相关性、时滞、异常与机器学习五大算法模块，对外输出统一的标准化结果结构；
- **安全执行层（sandbox）**：以子进程隔离为核心的代码沙箱，承担责任隔离、危险代码校验、目录限制与超时控制；
- **智能体层（agent + report）**：意图解析、代码生成与自修复、执行编排、报告生成四大能力，串联分析与输出的全流程；
- **交互层（app）**：基于 Streamlit 的纯 Python Web 界面，提供数据管理、自然语言分析、算法工具箱与系统状态四个页签。

技术栈为 Python 3.10+ + Streamlit + DeepSeek API（兼容 OpenAI 协议）+ pandas/numpy/scipy + scikit-learn + matplotlib/seaborn，全流程无独立 HTML/JS/CSS 代码。

## 五、项目创新点与应用价值

### 5.1 创新点

1. **"提问—代码—沙箱—报告"全链路闭环**：把大模型从"聊天工具"升级为"受控分析引擎"，实现从自然语言到可交付分析结论的端到端自动化；
2. **面向工业场景的五道安全防线**：进程级隔离、AST 白名单校验、目录权限限制、执行超时控制、环境变量脱敏共同构成可解释、可验证的代码执行安全体系；
3. **规则与模型双通道意图解析**：LLM 可用时由大模型生成高度定制化分析代码，不可用时自动回落本地模板，保证系统在离线/无密钥环境仍完整可用；
4. **工业特色的时滞分析能力**：通过互相关函数量化变量间的"先动后动"传导关系，并把滞后步数换算为工艺时间单位，直接支撑调节提前量设计；
5. **稳健统计的工程化取舍**：3σ 异常检测同时给出 MAD 稳健阈值对照，避免重尾、偏态分布下的误报，体现工业数据处理的严谨性。

### 5.2 应用价值

- **降本增效**：工艺人员无需编程即可完成日常数据分析，单次分析由小时级压缩至分钟级；
- **知识沉淀**：统一的算法库与分析口径，避免"每人一套脚本、结论无法比对"的工程顽疾；
- **安全可控**：沙箱机制为企业在生产网络中引入大模型提供了最小可行方案，风险边界清晰可验证；
- **可扩展底座**：算法层与智能体层解耦，后续可平滑接入时序预测、软测量、工况识别等更复杂的工业智能应用。
