# 产品使用手册

> 命题方：和利时企业命题 ｜ 项目名称：工业数据分析 Agent 系统 ｜ 文档类型：产品使用手册

## 一、产品功能架构

系统由四个界面功能区与五个能力层构成：

- **交互层（Web 界面）**
  - 数据文件管理：上传 CSV / 数据集列表 / 数据画像 / 数据预览 / 缺失值分析 / 删除文件
  - 自然语言分析：示例问题填充 / 需求输入 / 执行流程展示 / 生成代码查看 / 沙箱详情 / 图表与报告
  - 算法工具箱：基础统计 / 相关性分析 / 时滞分析 / 异常检测 / 模型训练 / 模型推理
  - 系统状态：模型与密钥配置 / 沙箱策略 / 运行统计 / 安全说明 / 分析历史
- **智能体层**：意图解析 → 代码生成（含自动修复）→ 执行编排 → 报告生成
- **安全执行层**：代码沙箱（进程隔离 / 静态校验 / 目录限制 / 超时控制 / 环境脱敏）
- **算法能力层**：基础统计 / 相关性 / 时滞 / 异常检测 / 机器学习
- **数据与配置层**：业务数据目录 / 配置与环境变量 / 输出产物（图表、报告、模型、历史记录）

## 二、运行环境与部署说明

### 2.1 环境要求

- 操作系统：Windows 10/11、Linux 或 macOS；
- Python 版本：3.10 及以上（推荐 3.11 / 3.12）；
- 依赖库：pandas、numpy、scipy、scikit-learn、joblib、matplotlib、seaborn、openai、python-dotenv、streamlit；
- 网络：可选。使用 DeepSeek 大模型生成分析代码与报告时需可访问外网；离线环境下系统自动使用本地模板模式，功能完整可用。

### 2.2 目录说明

- `config/`：配置文件目录，`.env` 保存 API 密钥与运行参数；
- `data/`：业务数据目录，存放上传或拷贝的 CSV 文件；
- `output/`：输出目录，`charts/` 存图表、`reports/` 存报告、`models/` 存模型；
- `analytics/`、`agent/`、`sandbox/`、`report/`：算法库、智能体、沙箱与报告生成模块；
- `app.py`：系统主程序入口；`requirements.txt`：依赖清单；`docs/`：项目交付文档。

### 2.3 部署步骤

1. 安装 Python 3.10+ 并确认 `python --version` 可用；
2. 在项目根目录安装依赖：`python -m pip install -r requirements.txt`；
3. 编辑 `config/.env`，将 `DEEPSEEK_API_KEY` 填写为真实密钥（仅做离线演示时可留空）；
4. 如需对接特定模型，可调整 `CODE_MODEL`（代码生成模型）、`REPORT_MODEL`（报告生成模型）与 `FALLBACK_MODEL`（模型不可用时的备选模型）；
5. 按需调整 `SANDBOX_TIMEOUT`（沙箱超时秒数）、`SANDBOX_MEMORY_MB`（内存上限）、`MAX_UPLOAD_MB`（上传大小上限）等参数。

## 三、系统启动操作步骤

1. 打开命令行终端，进入项目根目录；
2. 执行启动命令：`streamlit run app.py`；
3. 终端将输出本地访问地址（默认 `http://localhost:8501`），浏览器自动打开系统界面；
4. 在左侧边栏确认运行设置：LLM 开关状态、沙箱执行超时、代码自动修复轮数，以及当前是否已识别到 API 密钥；
5. 若侧边栏提示"未检测到 API Key"，系统处于本地模板模式，全部功能仍可正常演示；
6. 关闭系统：在终端按 `Ctrl + C` 终止服务。

**环境自检（可选）**：在项目根目录执行 `python -m pytest tests -q`，可运行全量单元与集成测试，用于确认部署环境完好。

## 四、完整使用流程

用户上传 CSV 数据 → 系统读取数据并识别字段与类型 → 用户在"自然语言分析"页签输入中文需求（或选择示例问题）→ 系统解析分析意图 → 生成分析代码 → 静态安全校验（不通过则自动修复重试）→ 沙箱子进程执行 → 回传结构化结果与图表 → 组织事实数据生成分析报告 → 界面展示结论、指标、图表与报告，并提供报告下载 → 分析记录归档至历史。

## 五、典型操作示例

> 以下示例均以项目自带的示例数据 `data/sample_process_data.csv`（720 行 × 8 列，含时间列、数值列与分类列）为例，实际使用时替换为自己的数据即可。

### 示例一：数据上传与基础描述性统计

**操作步骤**

1. 进入"数据文件管理"页签，点击上传区域选择本地 CSV 文件，点击"保存到 data 目录"；
2. 在文件列表中选择刚上传的文件，界面自动展示数据画像：总行数、总列数、数值字段数、时间字段数，以及每个字段的类型、缺失率与样例值；
3. 调整"预览行数"滑块查看数据前若干行；
4. 切换到"自然语言分析"页签，在"选择数据文件"中选中该文件；
5. 点击示例问题"请统计 inlet_temp_c 的均值、标准差、最大值和最小值"，或直接输入"统计 inlet_temp_c 的均值与标准差"；
6. 保持"生成分析报告"勾选，点击"开始分析"。

**预期效果**

- 执行流程时间线依次显示：确定数据文件 → 读取数据并识别字段 → 解析分析意图（基础描述性统计）→ 生成分析代码（LLM 或本地模板）→ 沙箱安全执行 → 自动生成报告；
- 页面顶部指标卡显示识别意图、代码来源、执行状态与总耗时；
- 生成代码区展示本次实际执行的分析代码，沙箱详情区展示退出码、耗时与结构化结果；
- 图表区呈现所统计字段的分布直方图（含均值与中位数参考线）；
- 报告区给出各字段的均值、标准差、极值区间与波动性解读，并提供 Markdown / HTML 报告下载。

### 示例二：相关性分析与异常检测

**操作步骤**

1. 在"自然语言分析"页签确认已选中目标数据文件；
2. 输入"分析各变量之间的相关性，找出强相关特征对"，点击"开始分析"；
3. 分析完成后，查看相关性热力图与强相关特征对清单；
4. 再次输入"用 3σ 原则检测 inlet_temp_c 和 steam_flow_t_h 的异常点"，点击"开始分析"；
5. 查看异常检测结果表中的异常点数量、占比与上下阈值，并结合异常分布图定位异常位置。

**预期效果**

- 相关性分析：输出相关性热力图，报告给出最强相关特征对（含相关系数、强弱等级与正负方向）以及强相关特征对的数量与列表，可用于工艺变量解耦与特征筛选；
- 异常检测：逐字段给出异常点数量、异常比例、3σ 上下界与偏离倍数 Top-N 明细，同时提供基于中位数的稳健阈值作为对照，避免重尾分布误报；
- 检测到的异常点在时序图中以橙色散点高亮，阈值线以红色虚线标注，便于快速定位仪表跳变或工况切换。

### 示例三：机器学习建模与报告导出

**操作步骤**

1. 在"自然语言分析"页签输入"训练随机森林模型预测 yield_pct，输出 R2 与特征重要性"，点击"开始分析"；
2. 分析完成后查看评估指标卡（R²、MSE、RMSE、MAE）与特征重要性排序；
3. 记录沙箱详情区展示的模型保存路径（位于 `output/models/`）；
4. 在"算法工具箱"页签选择"模型推理预测"，模型路径留空即自动使用最新模型，点击"执行推理"，查看预测条数、预测均值与预测明细；
5. 返回分析页签，在报告区点击"下载 Markdown 报告"或"下载 HTML 报告（图表内嵌）"完成报告导出。

**预期效果**

- 建模输出测试集 R²、RMSE、MAE 与 K 折交叉验证的 R² 均值/标准差，训练集与测试集 R² 并列展示以便识别过拟合；
- 图表区呈现"预测值 vs 实测值"散点图、残差分布直方图与特征重要性柱状图；
- 模型以文件形式持久化，推理阶段自动按保存时的特征顺序对齐，保证训练与推理一致性；
- HTML 报告为自包含单文件（图表以 Base64 内嵌），可直接提交或分享，无需附带图片目录。

## 六、常见问题与排查指南

| 现象 | 可能原因 | 排查与解决 |
| --- | --- | --- |
| 界面提示"未检测到 DEEPSEEK_API_KEY" | `config/.env` 未填写密钥或变量名拼写有误 | 打开 `config/.env` 确认 `DEEPSEEK_API_KEY=` 后有值；保存后刷新页面（或点击侧边栏"清除界面缓存并重载"） |
| 提示"LLM 调用失败"，但仍能出结果 | 网络不通、密钥无效或余额不足 | 检查网络与密钥有效性；系统已自动回落本地模板模式，功能不受影响 |
| 提示"模型不可用，已自动降级" | 所配置模型名在服务端不存在 | 系统已自动改用备选模型；如需固定，可在 `.env` 中把 `CODE_MODEL`/`REPORT_MODEL` 改为服务端实际支持的模型名 |
| 生成代码被拦截并提示"安全校验未通过" | 代码包含系统级模块导入、危险函数或越界路径 | 查看沙箱详情区的逐条违规明细；LLM 模式下系统会自动请求模型修复，连续失败时可改用示例问题或调整提问表述 |
| 提示"执行超时，进程树已强制终止" | 分析逻辑耗时过长或存在低效写法 | 在侧边栏调大"沙箱执行超时"；或先对数据做抽样、缩小参与计算的字段数量 |
| 图表中文显示为方块 | 运行环境缺少中文字体 | 在操作系统中安装常见中文字体（如微软雅黑、黑体），或使用具备中文字体的 Linux 镜像 |
| 上传数据后字段类型识别不合适 | 时间列被读成文本、数值列含非数字字符 | 检查原始 CSV 的编码与列格式；对含单位或千分位的数值列先清洗后再上传 |
| 分析中文乱码（如"锟斤拷"） | CSV 使用了非 UTF-8 编码 | 系统已自动尝试 GBK 等编码；若仍异常，建议用 Excel 另存为 UTF-8 编码的 CSV 后重新上传 |
| 页面长时间无响应 | 数据量过大或沙箱正在执行 | 观察"执行流程"提示；必要时刷新页面，或降低单次分析的数据规模 |
| 删除文件后无法找回 | 删除为不可恢复操作 | 删除前请确认已备份；建议保留原始数据副本 |
| PPT 生成脚本报错缺少模块 | 未安装 python-pptx | 执行 `python -m pip install python-pptx` 后重新运行脚本 |
